# Remove the category system — plan

Status: **planned.** Step 1 of [recurring-products-plan.md](recurring-products-plan.md). Delete this file once it lands.

## How

Delete the feature **end to end in one change**, starting at the source and working toward the screen:

1. **The model stops producing categories** (extraction schema + prompt).
2. **The worker stops copying them** into draft rows.
3. **The database drops the column** (autogenerated migration) and storage stops filtering by it.
4. **The API stops accepting, filtering, summarizing, and returning them.**
5. **The web app** loses the badge, the filter, the mix bar and chips, the table column, the category pickers, and the color tokens.
6. **Tests and docs** are updated in the same change.

After each deletion, remove whatever it leaves unused: imports, props, state, wrappers, CSS. No code is commented out and nothing is kept as a stub for step 2. Step 2 writes the new category system fresh.

Work on a feature branch. The branch is not merged on its own: it merges together with step 2, so `main` is never without categories. Existing data is not migrated; the dev database is reset later (plan step 8).

**Done when:**
- `git grep -niI categor -- ':!docs/product' ':!apps/api/alembic/versions' ':!docs/BUILD_AND_LEARN.md' ':!docs/design/*-prompt.md'` returns nothing
- `make test` and `uv run --group dev pytest packages/ai/tests -q` pass
- `pnpm --dir apps/web lint`, `typecheck`, and `build` pass
- `alembic upgrade head` then `alembic downgrade -1` both run on a scratch database

## What stays

Everything not about categories: period, range, source, and search filters; total, bill count, item count, average per bill, and the month comparison in the summary; bills and items views; inline name and amount editing; `requires_review` warnings.

## Order of work (one branch, small commits)

1. AI schema, prompt, and ai tests.
2. Worker mapper and tests.
3. Storage model, crud, and migration.
4. API modules and api tests.
5. Web: delete `CategoryBadge.tsx`, fix every compile error it causes, then CSS tokens, types, hooks, and layout.
6. Docs.
7. Run the "Done when" checks.

Deleting `CategoryBadge.tsx` and `SpendItem.category` first makes the compiler and tests list every remaining reference; step 5 relies on that.

## Risks

| Risk | Mitigation |
|---|---|
| Missing a reference | The compiler, tests, and the `git grep` gate |
| Layout gaps where badges sat | Inputs go full width; check the review dialog, bill rows, and add-line row at mobile and desktop widths |
| Branch drifts from `main` while step 2 is built | Rebase often; step 2 builds on this branch |
